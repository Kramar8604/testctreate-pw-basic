# Playwrite basics

This project is a basic UI automation testing suite built with **Playwright** and **TypeScript**. It is designed to test the login functionality of the [Practice Software Testing](https://practicesoftwaretesting.com/) website.

## Project Overview

The suite focuses on implementing best practices in automation, including:

* **Custom Locators**: Using `data-test` attributes for robust element selection.
* **Smart Assertions**: Verifying URLs (using RegEx), page titles, and UI content.
* **Configuration**: Optimized setup for Chromium browser and UI debugging mode.
